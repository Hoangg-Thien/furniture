# IV) Bảng kế hoạch thực hiện dự án (Project Implementation Plan)

### 1. Lộ trình tổng quan theo giai đoạn (Phases & Milestones)

Dự án được xây dựng và triển khai theo mô hình Agile/Scrum kết hợp Waterfall cải tiến trong thời gian dự kiến **16 tuần**:

| Giai đoạn (Phase) | Thời gian dự kiến | Mục tiêu chính | Kết quả bàn giao (Deliverables) |
| :--- | :--- | :--- | :--- |
| **P1: Khảo sát & Phân tích yêu cầu** | Tuần 1 - Tuần 2 | Thu thập nghiệp vụ bán hàng, nhập kho, giao lắp nội thất; chốt phạm vi dự án | Tài liệu SRS (Đặc tả yêu cầu), Bản mô tả chức năng |
| **P2: Thiết kế hệ thống & UI/UX** | Tuần 3 - Tuần 4 | Thiết kế CSDL PostgreSQL, kiến trúc hệ thống, wireframe & mockup UI | Sơ đồ ERD (`sales.sql`), Wireframe UI/UX (Figma/Mockup), Kiến trúc Client-Server |
| **P3: Phát triển Backend & API lõi** | Tuần 5 - Tuần 8 | Xây dựng RESTful API, xác thực JWT, nghiệp vụ kho, đơn hàng, khuyến mãi | Bộ API hoàn chỉnh kèm tài liệu Swagger/Postman, CSDL migration |
| **P4: Phát triển Frontend & Mobile** | Tuần 9 - Tuần 12 | Xây dựng Admin Dashboard, Web bán hàng và Ứng dụng Mobile Android | Web Client (React/Vite), Quản trị viên (Admin Portal), File APK Android |
| **P5: Kiểm thử & Đảm bảo chất lượng** | Tuần 13 - Tuần 14 | Kiểm thử chức năng, luồng tính tiền/voucher phức tạp, hiệu năng tải ảnh nội thất | Bảng kịch bản kiểm thử (Test Cases), Báo cáo bug & kết quả kiểm thử |
| **P6: Triển khai & Đóng gói đồ án** | Tuần 15 - Tuần 16 | Triển khai server, đóng gói file APK, hoàn thiện tài liệu hướng dẫn và báo cáo | Source code hoàn chỉnh, Server chạy thực tế, File APK, Báo cáo đề tài |

### 4. Kế hoạch quản trị rủi ro (Risk Management Plan)

| Rủi ro tiềm ẩn | Mức độ | Tác động | Giải pháp phòng ngừa & Xử lý |
| :--- | :---: | :--- | :--- |
| **Sai lệch tính tiền khi kết hợp nhiều khuyến mãi/voucher** | Cao | Thất thoát tài chính hoặc khách hàng khiếu nại | Thiết lập cơ chế kiểm tra điều kiện chặt chẽ trong CSDL (Check Constraints, Triggers); ưu tiên áp dụng theo thứ tự: Giảm giá sản phẩm -> Khuyến mãi đơn hàng -> Voucher code. |
| **Bất đồng bộ số lượng tồn kho giữa mua Online & Tại quầy** | Cao | Bán vượt quá số lượng hàng có trong kho (Overselling) | Áp dụng Transaction (ACID) khi thanh toán và giữ hàng trong giỏ trong một khoảng thời gian cố định (reservation window). |
| **Tải ảnh sản phẩm nội thất chậm do độ phân giải cao** | Trung bình | Trải nghiệm người dùng kém, giảm tỷ lệ chuyển đổi | Nén ảnh tự động khi upload, sử dụng định dạng WebP, hỗ trợ CDN và lazy loading ở Client. |
| **Trễ tiến độ giao hàng & lắp đặt nội thất** | Trung bình | Khách hàng không hài lòng, ảnh hưởng uy tín thương hiệu | Bổ sung module theo dõi trạng thái giao lắp chi tiết (`Đang chuẩn bị hàng` -> `Đang vận chuyển` -> `Đang lắp đặt` -> `Đã nghiệm thu`). |
